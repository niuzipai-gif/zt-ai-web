# ZT.AI 公开展示页改版设计

## 目标

把精选项目页和简历摘要页从概览壳子改成可用于求职展示的公开作品页，同时统一简历下载文件、更新头像，并提供一个与现有飞书 Bot 习惯一致的本地后端静默启动入口。

## 范围

- 精选项目页保留当前三张项目卡，GitHub 精选仓库卡片改为真实跳转到 `https://github.com/niuzipai-gif?tab=repositories`。
- 简历摘要页直接基于用户确认的 `蔡宙廷_个人简历.docx` 内容，组织为个人信息、核心数据、工作经历、坤信岗位详述、项目经历、技能证书、教育背景和可迁移工作方法。
- 网站头像使用用户提供的西装照片；聊天页、简历页共用同一资源。
- `public/resume.docx` 替换为用户指定的简历文件，所有网页下载入口继续指向同一 URL。
- 新增 `start-gateway.ps1` 和桌面 `.lnk`，静默启动本地 Node 网关；已有进程监听 8790 时不重复启动。

## 不在范围内

- 不把 Agent 操作能力加入网页版。
- 不改变聊天上下文持久化、模型切换、Markdown、附件和 MMX 隐式能力。
- 不把 API key 写入前端、仓库或快捷方式参数。

## 页面与交互

精选项目页使用现有灰白毛玻璃视觉系统。GitHub 卡片整体为可点击 `<a>`，新窗口打开并带 `rel="noreferrer"`，让面试官可以直接进入仓库列表。

简历页使用纵向信息层级：顶部个人身份和下载入口，随后用数据卡突出 `8+ 个/月`、`约 2 倍`、`30 分钟/套`、`月度利润贡献 ≥ 2 万元`，再按时间和主题展开经历。移动端所有卡片改为单列，正文保持可读字号和自然间距。

## 本地启动

快捷方式调用 Windows PowerShell 的隐藏窗口模式，执行 `start-gateway.ps1`。脚本读取项目内 `aikey.env`，工作目录固定为 `E:\ZT.AI\zt-ai-web`，日志写入被 Git 忽略的 `server-gateway.log`。快捷方式图标使用项目内 ZT.AI 金色 Logo 的 ICO 资源。

## 验收标准

1. `npm test` 和 `npm run build` 通过。
2. 精选项目页 GitHub 卡片的 href 与目标 URL 完全一致。
3. 简历页包含指定简历中的所有主要内容，不再只展示两张概览卡。
4. 聊天页和简历页显示西装头像；下载 `/resume.docx` 与指定源文件大小一致。
5. 桌面快捷方式存在，目标为隐藏 PowerShell 启动脚本；重复点击不会启动第二个 8790 网关。
6. GitHub Pages 构建产物可加载，线上 `resume.docx` 返回 200，页面源码不包含 API key。
