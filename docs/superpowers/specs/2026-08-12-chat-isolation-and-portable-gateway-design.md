# ZT.AI 会话隔离与可迁移网关设计

## 目标

让每个公开访问者拥有独立的访客身份和聊天记录，在此身份下支持多条可恢复会话；同时把本地网关、依赖安装说明、启动脚本和配置模板打包到桌面，方便换电脑迁移。

## 隐私边界

- 浏览器首次访问生成随机 `visitorId`，只存储在当前浏览器的 `localStorage`。
- 聊天数据按 `visitorId` 分区保存；会话记录不再使用单一全局 key。
- 新建聊天只创建当前访客的新会话，不会删除旧记录，也不会读取其他访客的记录。
- 网关请求只接收当前会话的消息历史，不在服务端持久化聊天内容，不用 IP 作为身份，也不把访客历史广播给其他人。
- 清除浏览器站点数据会丢失该浏览器的本地记录，这是公开免登录模式的明确边界。

## 交互

- 聊天页顶部增加“聊天记录”按钮，打开右侧桌面抽屉、手机端侧滑抽屉。
- 抽屉顶部提供“新建聊天”；列表显示会话标题、最近更新时间和消息数。
- 当前会话标题由第一条用户消息生成，没有用户消息时使用“新建聊天”。
- 切换历史会话只切换当前访客本地数据；模型切换仍只影响下一次请求，不清空会话。
- 抽屉底部显示当前访客 ID 的短标识和“记录仅属于当前访客”的隐私说明。

## 可迁移网关

- 桌面压缩包包含 `server/`、`package.json`、`package-lock.json`、`public/resume.docx`、`src/`、启动脚本、`.env.example` 和迁移说明。
- 不包含 `node_modules`、`dist`、日志、`.git` 和真实 `aikey.env`，避免压缩包过大或泄露密钥。
- 包内提供 `aikey.env.example`，迁移到新电脑后复制为 `aikey.env` 并填入私密 key。
- 启动脚本不依赖固定盘符：以脚本所在目录作为项目根目录；端口 8790 已有监听时不重复启动。
- 桌面交付两个压缩包：`ZT.AI-网关-离职迁移包.zip`（轻量源代码包）和 `ZT.AI-网页完整项目备份.zip`（含完整 Git 工作区但仍排除密钥、依赖和构建缓存）。

## 验收

1. 两个浏览器上下文分别生成不同 visitorId，互不读取消息记录。
2. 同一浏览器能新建、切换、恢复至少三条会话；刷新后当前会话和列表仍存在。
3. 模型切换保留当前会话历史；新建聊天显示空白欢迎态。
4. 桌面端和 390px 手机宽度下抽屉可打开/关闭，页面无横向溢出。
5. `npm test`、`npm run build` 通过，迁移包可在解压目录执行 `npm install` 和启动脚本。
6. 公网前端和 Render 网关仍正常，前端包不包含 API key。
