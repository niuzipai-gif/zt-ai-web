## Behavior

- Only the exact fixed phrase and supported language can use the corresponding recording. Audio is fetched after opening voice mode, not during initial page loading.
- HTTPS download has a 2-second limit. Exact byte length and SHA256 must match before a local Blob is played; this avoids a duplicate media download. Missing, corrupt or slow assets fall back to the original synthesis request.
- Closing voice mode cancels preparation, stops playback and releases local audio URLs. A canceled operation cannot start a fallback request.
- Playback and greeting state both accept only a local, nonopaque Blob origin or the existing HTTPS audio path. A candidate UI-state bug was found and fixed before replacing the production entry.
- The real backend capability gate remains in place. A prepared clip cannot make a sleeping/unavailable backend appear ready.

## Remaining limits

The static entry uses Cloudflare's global overseas route. It is free and requires no user-owned domain or ICP filing, but is not a mainland hosting deployment or a nationwide carrier guarantee. Render Free still sleeps when idle; its wake-up remains a separate wait. No end-to-end cold-start reduction percentage is claimed. On a slow static download, the bounded fallback can add up to about two seconds before normal synthesis. Repeated cached playback benefits depend on the browser's cache availability.
